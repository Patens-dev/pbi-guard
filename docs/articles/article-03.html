How to Use AI to Handle Power BI (Interactive Guide)

Published September 2026 • 5 min read • By PBI Guard Core Team

Creating dozens of tables and measures by hand in Power BI Desktop is slow. You can now use AI to author and modify data models in TMDL format inside Visual Studio Code. Follow this 10-step setup to connect VS Code, GitHub Copilot, and Power BI.

0 of 10 Steps Completed
1 VS Code
📍 Web Browser

Install Visual Studio Code

Install Visual Studio Code on your machine to use it as your model editor.

Official Microsoft Download Open code.visualstudio.com ↗
2 Power BI
📍 Microsoft Store or Direct Download

Install Power BI Desktop

Power BI Desktop is required. Its local engine evaluates measures while you edit files in VS Code.

Free Download from Microsoft Get Power BI Desktop ↗
3 VS Code
📍 Bottom-left corner: Accounts icon

Sign In with GitHub

Open VS Code, click the Accounts icon in the lower-left corner, and sign in with your GitHub account containing an active Copilot subscription.

4 VS Code
📍 Extensions Tab (Ctrl+Shift+X)

Install the Power BI Modeling MCP Extension

In the Extensions view, search for Power BI Modeling MCP published by Microsoft and click Install.

5 Power BI
📍 Windows Desktop

Launch Power BI Desktop

Start Power BI Desktop and keep it running in the background.

6 Power BI
📍 Ribbon: Home > Get Data

Open or Create a Report

Open an existing report or load sample data (such as Financial Sample) into a blank file.

7 Power BI
📍 File > Save As

Save as Power BI Project (*.pbip)

Select Save As and choose Power BI Project (*.pbip). This separates the report into human-readable TMDL text files on disk.

8 VS Code
📍 File > Open Folder

Open the PBIP Directory in VS Code

In VS Code, open the folder where you saved the .pbip file. Your model tables and definitions will appear in the sidebar explorer.

9 VS Code
📍 Activity Bar: Copilot Chat

Enable Agent Mode

Open Copilot Chat, switch mode to Agent Mode, and confirm that the Power BI MCP tools are enabled.

10 VS Code
📍 Copilot Chat Prompt Input

Prompt Copilot to Build

Describe the tables or measures you need. Copilot will inspect the schema and write the TMDL definitions automatically:

Inspect my model. Create a complete Calendar table in TMDL using CALENDARAUTO with Year, Month, and Quarter columns.

Once Copilot writes the files, switch back to Power BI Desktop. The changes sync into your workspace automatically.

Prevent Formula Drift

Keep AI Changes Under Control

When using AI or collaborating on Power BI models, freeze your verified checkpoints so you can catch unexpected formula alterations in 30ms.
