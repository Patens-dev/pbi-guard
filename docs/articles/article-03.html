Power BI Desktop gets painfully slow when you build dozens of tables and measures by hand. You can now skip the desktop clicks and let AI generate your entire data model inside Visual Studio Code. Use this interactive guide to walk through the exact setup.

0 of 10 Steps Completed
1 VS Code
📍 Web Browser

Install Visual Studio Code

You need Visual Studio Code installed on your machine as your code and model editor.

Official Microsoft Download Open code.visualstudio.com ↗
2 Power BI
📍 Windows Store or Microsoft Download

Install Power BI Desktop

Power BI Desktop is mandatory. The local Analysis Services database engine runs inside it while you edit files in VS Code.

Free Download from Microsoft Get Power BI Desktop ↗
3 VS Code
📍 Bottom-left corner: Accounts gear icon

Log In to VS Code with GitHub

Launch VS Code. Look at the bottom-left corner of the window. Click the Accounts icon and sign in with your GitHub account. Verify that you have an active GitHub Copilot subscription.

4 VS Code
📍 Left activity bar: Extensions tab (Ctrl+Shift+X / Cmd+Shift+X)

Install the Power BI Modeling MCP Extension

Open the Extensions view. Search for Power BI Modeling MCP (or Power BI Authoring MCP Server) published by Microsoft. Click Install.

5 Power BI
📍 Windows Desktop / Start Menu

Launch Power BI Desktop

Open Power BI Desktop. Keep it open in the background so its local engine stays active.

6 Power BI
📍 Top Ribbon: Home > Get Data

Open or Create a Report

Open an existing report file, or create a new blank report and connect to any sample data source like Financial Sample or an Excel sheet.

7 Power BI
📍 Top Menu: File > Save As > File Type Dropdown

Save as Power BI Project (*.pbip)

Click File, click Save As, and change the file type dropdown from .pbix to Power BI Project (*.pbip). Select a clean folder and save. This splits your model into plain text TMDL files.

8 VS Code
📍 Top Menu: File > Open Folder

Open the PBIP Folder in VS Code

Switch back to VS Code. Click File, select Open Folder, and choose the root PBIP folder you saved in step 7. You will see your dataset tables listed as text files inside the sidebar.

9 VS Code
📍 Left activity bar: GitHub Copilot Chat (Ctrl+Alt+I / Cmd+Alt+I)

Enable the Power BI MCP Tool in Copilot

Open Copilot Chat. Switch the mode dropdown from "Chat" to Agent Mode. Click the tools wrench icon near the text box and confirm that the Power BI MCP tools are checked and active.

10 VS Code
📍 Copilot Chat Prompt Input

Tell Copilot What to Build

Type what you want Copilot to create. It will inspect your model schema and write the TMDL files directly. Test any of these prompt presets:

Inspect my model. Create a complete Calendar table in TMDL using CALENDARAUTO with Year, Month, and Quarter columns.

Once Copilot finishes writing, switch back to Power BI Desktop. Your new tables and measures will appear immediately on your canvas.
